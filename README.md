# 📈 Real-Time Stock Market Dashboard

A Python-based interactive stock market dashboard built using
Streamlit, Pandas, Plotly and yFinance.

## 🚀 Features

- Real-time/latest available stock market data
- Stock price tracking
- Interactive price charts
- Candlestick charts
- Trading volume analysis
- 20-day and 50-day moving averages
- RSI indicator
- Daily returns
- Stock comparison
- Performance comparison
- 52-week high and low
- Stock watchlist
- SQLite database
- Latest stock news
- CSV data download
- Automatic data refresh

## 🛠️ Technologies

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- yFinance
- SQLite
